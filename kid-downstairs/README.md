# 小朋友下樓梯

這是一個以經典 Flash 遊戲「小朋友下樓梯」為靈感的網頁小遊戲。玩家需要左右移動角色，
踩在不斷往下延伸的樓梯上，避免跌出畫面下方並挑戰更高的分數。

## 遊玩方式

- 鍵盤：使用左右方向鍵或 A / D 鍵移動。
- 觸控：在手機或平板上按住畫面左半部 / 右半部控制方向。
- 空白鍵或 Enter：開始或重新開始遊戲。
- R：在結束畫面快速重新開始。

## 進行遊戲

只要在瀏覽器中開啟 `index.html` 即可開始遊戲，無需額外安裝套件。

## 遊戲特色

- Canvas 2D 繪製的柔和霓虹風格畫面與簡單動畫。
- 隨機產生的樓梯路線，節奏會隨著時間逐漸加快。
- 本地儲存最高分數，隨時挑戰自己的極限。
